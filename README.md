# Mukul Editz Portfolio

A dark futuristic animated portfolio website for Utkarsh Mudila's graphic design journey under the studio name **Mukul Editz**.

## Features

- Animated hero section with futuristic neon styling
- Project showcase cards for graphic design work
- Design journey timeline
- Services marquee
- Contact links for Email, Instagram, Behance, and LinkedIn
- Responsive layout for mobile and desktop
- Dependency-free local development and static build scripts

## How to Run It

You do **not** need to install any npm packages for this version.

1. Open a terminal in this project folder.
2. Start the local website server:

   ```bash
   npm run dev
   ```

3. Open this URL in your browser:

   ```text
   http://localhost:4173
   ```

4. To stop the server, press `Ctrl + C` in the terminal.

## Build for Sharing or Deployment

Create a static copy of the website in the `dist` folder:

```bash
npm run build
```

Then preview the built version:

```bash
npm run preview
```

Open this URL in your browser:

```text
http://localhost:4173
```

## Add Your Images

The current project cards are polished placeholders. Replace the placeholder cards in `src/main.js` with your actual portfolio images when your design exports are ready.
